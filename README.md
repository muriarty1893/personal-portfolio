## About

Static portfolio website with a separate React/Vite notes layer. The portfolio pages remain plain HTML; the English-only notes index lives at `blog.html` and articles at `blog-post.html`, both styled after a quiet editorial reading page.

## Development

```bash
npm install
npm run dev
```

Build the portfolio and blog into `dist` with `npm run build`.
